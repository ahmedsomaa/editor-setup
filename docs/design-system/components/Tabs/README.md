Pill segmented control for switching a view in place (Font and Theme, Code and Window, VS Code and Cursor). Track `muted` with a 1px `border`; the active thumb is `card` with a 1px `border`.

The consumer provides two to four short labels and the active value. Use real `button`s with `aria-pressed` inside a labelled group. Not for navigation between pages: that is the nav bar.
