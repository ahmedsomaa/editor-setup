Pill button in four variants: `default` (ink, one per view), `outline`, `secondary` and `ghost`. Sizes: 36px (`sm`), 40px, 48px (`lg`, for the hook).

The consumer provides a verb-first label and, optionally, a 16px Phosphor icon before it. There is no shadow. Hover shifts colour (`primary-hover`, `muted`); press scales to 0.98. Disabled drops to 50% and ignores the pointer. Focus is a solid 2px `ring`.

- Do: one default button per view, label of one to three words.
- Don't: fill a button with `accent`, use a rectangle, or put an icon after the label unless it is an arrow that means "go".
