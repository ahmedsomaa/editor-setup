Brief

Scope for the EditorSetup site.

Meta

Product
EditorSetup
Platform
Website first
Purpose
A git-backed Registry of Font and Theme Pairs, each with Settings and a Snapshot for an Editor.

Problem

A developer finds a monospace Font and a Theme that look good together, then has to reconstruct the Settings for their own Editor. Screenshots on social sites are personal, inconsistent, and missing the Settings. Paid Fonts and Themes cannot be rendered live on a public site.

Who

  • Visitors browse the Registry, open a Pair, copy Settings, and Compare.

Goals

  • User goal: find a Pair, see it in their Editor, and copy the Settings.
  • Product goal: keep one public Pair per Font and Theme, with a Config only when both Settings and a Snapshot exist.
  • Success: a visitor leaves with Settings they can paste, judged from a Snapshot of the Editor they use.

Scope

In

  • Home, Registry, Pair, and Compare.
  • Search by Font and Theme. Filter by Editor, Appearance, License, Font, and Theme.
  • Pagination, a 16:9 Snapshot, and Settings as plain text with copy.
  • Launch Editors: VS Code, Cursor, Zed, and Neovim.

Out

  • Sign-in, account, profile, and admin.
  • An in-app Contribution form. Contribution is a pull request.
  • Score, votes, and trending.
  • Live preview of Paid Fonts, a drag-slider Compare, JetBrains, Helix, and email.

Features → Screens

Feature Screen What it shows
Home Home Like the scratch Registry index: sticky header, centered hook with Theme chip and Font underline, See Pair, search, Editor filters, text Pair cards, footer.
Registry (pilot) Registry Header, hook, search, tag filters, grid or list, Pairs, footer. No results is a state.
Pair Pair Header, Font, Theme, links, License, Appearance, Editors, Snapshot, Settings, footer.
Compare Compare Header, one Editor, two Pairs, Snapshots side by side, footer. A Pair with no Config for that Editor cannot be chosen.

Constraints

  • Brand: Untitled UI family. Violet primary #7F56D9, pill controls, hairline borders, quiet shadow. Sora for headlines, Geist for UI, Geist Mono for Settings. Mark is Lucide pencil-sparkles: pencil in ink, sparkles in violet.
  • Screens take .scratch/mp-cld-imp as a visual reference and must diverge in layout and detail. Neutrals stay gray, not violet-tinted.
  • Tech: this handbook is static. The site is a later static web build. Website first, readable on a phone.
  • A11y: WCAG AA for text on the surfaces the product uses.
  • Terms: Pair, Font, Theme, Appearance, Editor, Config, Settings, Snapshot, License, Registry, Compare, Contribution.
  • A Snapshot is 16:9. The site does not add a frame. One Pair per Font and Theme. One Config per Editor.
