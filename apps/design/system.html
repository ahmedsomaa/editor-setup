Design system

Untitled UI color, type roles, and pill controls, built for a Registry of Font and Theme Pairs.

Brand

Guidelines

The mark is Lucide pencil-sparkles. The pencil is ink. The sparkles are violet #7F56D9. It sits in the site header and as the app icon. The wordmark is Sora, and only in that lockup.

  • Do use the Lucide paths. Pencil in foreground, sparkles in primary.
  • Do keep the wordmark in Sora.
  • Don’t redraw the icon, and don’t set the wordmark in Geist.

Radius

Base --radius is 8px. Steps divide and multiply by φ. Buttons, search, filters, badges, and pagination are pills. Cards use the large step so a 16:9 Snapshot has a corner, not a capsule.

Elevation

Rest is a hairline. Raised is Untitled’s shadow-xs, for cards and fields. Overlay is shadow-lg, for a menu. Dark shadows get heavier; they are not flipped.

Icons

Lucide, one set. The mark is in that stroke family, and the Registry needs search, filter, and pager chevrons. Lucide icons.

Anti-slop

Don’t Do
Violet-tint the page, or lay a code-glyph pattern under it. Keep the page gray. Violet marks the action, the selected filter, and the sparkles.
Put Sora on filters, badges, and meta. Keep Sora on the hook and the Pair title.
Nest a card around the Snapshot, or lift it on hover. One card. Hover only darkens the hairline.
Use emoji, a score, or an upvote arrow. Say the License: Open, Free, or Paid.
Write “Awesome theme!!!”. Use the real names: Vitesse Dark, Inconsolata.
Put two primary buttons in one view. One primary action. On an empty Registry, that action is Clear filters.

Components

Pilot: Registry. Later: header, hero, footer, editor switch, Settings block, and Compare columns. Loading and inline errors are not Registry controls.

Don’t Do
Use primary for every filter. Keep primary for one action. Filters use the filter pill.

Search

Finds a Pair by Font name or Theme name.

.es-search {
  border: 1px solid var(--border);
  border-radius: var(--radius-pill);
  box-shadow: var(--shadow-raised);
}
.es-search:focus-within { box-shadow: var(--shadow-raised), var(--focus); }

Filter

One Editor, Appearance, License, Font, or Theme. Selected is the accent pill, not a second primary button. 

.es-filter.is-selected {
  background: var(--accent);
  color: var(--accent-foreground);
}
Don’t Do
Turn the selected Editor into a solid violet button. Use the accent fill and accent label.
